# 服务器部署说明

本文档使用通用占位路径和用户，请根据自己的服务器环境替换。

## 准备

服务器需要安装：

- Node.js 18 或更高版本
- npm
- Playwright/Chromium 运行所需依赖

默认端口：

```text
18765
```

访问地址：

```text
http://<server-ip>:18765/screen
http://<server-ip>:18765/admin
http://<server-ip>:18765/led
```

## 安装

```bash
mkdir -p /opt/rolling-screen
cd /opt/rolling-screen
git clone <your-repo-url> .
npm ci --omit=dev
cp .env.example .env
nano .env
npm run install:playwright:cn
npm run start
```

`.env` 至少按需填写：

```text
PORT=18765
BULLETIN_USERNAME=your_username
BULLETIN_PASSWORD=your_password
BULLETIN_LOGIN_URL=https://example.com/login
BULLETIN_LIST_URL=https://example.com/bulletins
```

如果不需要远程公告同步，可以保留占位值，并在管理页关闭该模块。

## 防火墙

需要放行 TCP 端口：

```bash
sudo ufw allow 18765/tcp
```

或按服务器发行版使用对应防火墙工具开放 `18765/tcp`。

## systemd 后台运行

创建服务文件：

```bash
sudo tee /etc/systemd/system/rolling-screen.service >/dev/null <<'EOF'
[Unit]
Description=Rolling Screen Dashboard
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=appuser
Group=appuser
WorkingDirectory=/opt/rolling-screen
Environment=NODE_ENV=production
Environment=HOME=/home/appuser
ExecStart=/usr/bin/node /opt/rolling-screen/server.js
Restart=always
RestartSec=5
KillSignal=SIGINT
TimeoutStopSec=20
StandardOutput=journal
StandardError=journal
SyslogIdentifier=rolling-screen

[Install]
WantedBy=multi-user.target
EOF
```

启用并启动：

```bash
sudo systemctl daemon-reload
sudo systemctl enable rolling-screen
sudo systemctl restart rolling-screen
```

查看状态和日志：

```bash
systemctl status rolling-screen
journalctl -u rolling-screen -f
```

## 定时同步公告图

Linux 可用 cron 定时执行：

```cron
0 10 * * * cd /opt/rolling-screen && /usr/bin/npm run fetch:bulletin:daily >> logs/fetch-bulletin.log 2>> logs/fetch-bulletin.err.log
```

脚本内部规则：

- 每天执行一次
- 失败后按 `.env` 中的重试间隔等待
- 每天最多尝试 `BULLETIN_DAILY_MAX_ATTEMPTS` 次
