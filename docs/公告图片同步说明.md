# 公告图片同步说明

本项目支持使用 Playwright 自动登录远程站点，进入指定列表页，查找公告图片入口，并把图片保存为本地文件，供大屏和 LED 小屏稳定展示。

公开版不包含任何真实站点、账号、密码或企业信息。使用前请在本地 `.env` 或管理页填写自己的配置。

## 环境变量

```text
BULLETIN_USERNAME=your_username
BULLETIN_PASSWORD=your_password
BULLETIN_LOGIN_URL=https://example.com/login
BULLETIN_LIST_URL=https://example.com/bulletins
BULLETIN_BUTTON_TEXT=公告图片下载
BULLETIN_BOARD_URL_CONTAINS=board-iframe
```

如果登录页选择器无法自动识别，可补充：

```text
BULLETIN_LOGIN_USERNAME_SELECTOR=input[name="username"]
BULLETIN_LOGIN_PASSWORD_SELECTOR=input[type="password"]
BULLETIN_LOGIN_BUTTON_SELECTOR=button[type="submit"]
```

## 同步规则

- 手动同步：在 `/admin` 点击“立即同步公告图片”
- 单次命令：`npm run fetch:bulletin`
- 每日任务：`npm run fetch:bulletin:daily`
- 失败重试次数由 `BULLETIN_DAILY_MAX_ATTEMPTS` 控制
- 重试间隔由 `BULLETIN_RETRY_DELAY_MINUTES` 控制

## 文件位置

脚本：

```text
scripts/fetch-bulletin-image.js
scripts/fetch-bulletin-daily.js
```

本地输出：

```text
uploads/device/bulletin/bulletin-YYYY-MM-DD.png
uploads/device/bulletin/latest-bulletin.png
uploads/device/bulletin/bulletin-YYYY-MM-DD-led.png
uploads/device/bulletin/latest-bulletin-led.png
uploads/device/bulletin/latest-bulletin-data.json
```

大屏默认读取：

```text
/uploads/device/bulletin/latest-bulletin.png
```

LED 小屏访问：

```text
http://<server-ip>:18765/led
```

## 截图和下载

脚本会优先识别包含 `BULLETIN_BOARD_URL_CONTAINS` 的公告页面地址，并使用浏览器渲染截图。截图倍率可通过以下变量调整：

```text
BULLETIN_CAPTURE_SCALE=2
```

如页面提供直接下载入口，脚本也会尝试生成小屏使用的 `latest-bulletin-led.png`。

## 常见问题

如果同步失败，建议依次检查：

- `.env` 是否填写真实账号、密码、登录页和列表页
- 服务器是否能访问远程站点
- Playwright Chromium 是否已安装
- 登录表单选择器是否需要手动指定
- 远程站点按钮文案是否与 `BULLETIN_BUTTON_TEXT` 匹配

国内环境可执行：

```bash
npm run install:playwright:cn
```

项目当前固定 `playwright@1.55.0`。升级 Playwright 前，请先确认目标服务器能下载对应浏览器包。
